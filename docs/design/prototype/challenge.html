Build a profile card with the box model

Objective

Style .card so it renders exactly 320px wide, centered, with 24px of inner space and a 1px border.

Every element is a box made of four layers: content, padding, border and margin. By default, width only sizes the content, so padding and border are added on top.

That is why a 320px card with 24px padding and a 1px border actually renders 370px wide. Changing box-sizing tells the browser to include padding and border inside the width you set.

Syntax

.box {
  box-sizing: border-box;
  width: 200px;   /* includes padding + border */
  padding: 16px;
}

Requirements

  1. .card has 24px paddingPassing
  2. A 1px solid border surrounds the cardPassing
  3. The card is horizontally centeredPassing
  4. Padding and border are included in the widthFailing
  5. The rendered card is 320px wideFailing
