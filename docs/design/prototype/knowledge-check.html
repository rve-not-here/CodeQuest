Question

Question 1 of 5 Which box-sizing value makes the declared width include padding and border?

Correct

Your answer
—

border-box makes the declared width the total width, so padding and border are drawn inside it. content-box is the default and adds them outside.

Question 2 of 5 What is this card’s rendered outer width? 
.card {
  width: 320px;
  padding: 24px;
  border: 1px solid;
  box-sizing: content-box;
}

Correct

Your answer
—

content-box is the default, so the rendered width is content plus padding plus border: 320 + 24 + 24 + 1 + 1 = 370px.

Question 3 of 5 With content-box sizing, which declaration pushes a sibling element away without changing the element’s border-box size?

Correct

Your answer
—

Margin sits outside the border and moves neighbours without changing the element’s own size. With content-box sizing, padding and border increase the border-box size. Outline is drawn outside the border and takes no space in layout at all.

Question 4 of 5 Two sibling div elements each have margin-block: 24px. What is the vertical gap between them? Assume the parent is a plain block container with no padding, border, or overflow, and that it is not a flex, grid, or other new formatting context, so adjacent vertical margins collapse.

Correct

Your answer
—

These two positive sibling margins collapse to the larger margin. Both are 24px, so the gap is 24px. Making the parent a flex or grid container prevents this sibling-margin collapse, giving a 48px gap. Parent padding, borders, or overflow alone do not prevent sibling margins from collapsing.

Question 5 of 5 With this content-box rule, what is this panel’s border-box height? 
.panel {
  height: 200px;
  padding: 32px;
  border: 2px solid;
  box-sizing: content-box;
}

Assume the standard box model with content-box. Padding applies to all four sides, so it adds 32px above and 32px below, and the border adds 2px above and 2px below.

Correct

Your answer
—

Total height is content plus padding plus border: 200 + 32 + 32 + 2 + 2 = 268px. 264px forgets the border, and 232px counts padding on only one side.
