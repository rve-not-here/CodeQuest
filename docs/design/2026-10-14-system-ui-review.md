| C. Historical full-system recommendation, superseded by the focused scope revision: A, Learning Lab. It makes learning instructions and classroom/admin records comfortable in SEAIT's bright teaching/defense environment, while the workspace remains large and task-focused. It requires a real composition change rather than a new dark accent. Choose B if continuity and the technical mission identity matter more; choose C if reading-led lessons are the priority. None is approved merely because it rendered successfully.

All three share the requested single top bar, role links, keyboard account/mobile disclosures, no persistent sidebar, responsive mounted editor modes, explicit Run/Save/Submit consequences, fullscreen preview, labeled semantic roster and actual outstanding-prerequisite language. Prototype Return-to-lesson navigation is limited to the comparison; final implementation must keep the actual route and server-selected Continue. Experiment and KC placement requirements are specified above, not claimed implemented by these three representative screens.
