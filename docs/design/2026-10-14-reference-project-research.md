# CodeQuest reference-project research

Research date: 2026-10-14. Scope: the eight requested primary references and two secondary references. This is a bounded comparison, not a survey of all programming education repositories.

## Evidence method

Read the repositories, selected frontend source files, official documentation and license files. Retrieved current source trees and branch revisions through the GitHub API when GitHub's rendered pages failed to load. No reference repository was installed or used to replace CodeQuest's Laravel stack.

Evidence grades:

- **Source inspected** means the named implementation was read. It does not certify the deployed service, authorization, grading security or accessibility.
- **Documented** means first-party documentation describes the behavior. It is not a locally executed workflow.
- **Public page inspected** means anonymous Chromium loaded the page and its rendered screenshot was visually reviewed. No reference account was created and no academic submission was made.

Anonymous public inspection covered freeCodeCamp's curriculum and legacy HTML lesson, Exercism's JavaScript track, CodeCombat's campaign map and Kur00o's login. Each returned HTTP 200. Kolibri's official coach screenshot was viewed in the published guide. Their authenticated dashboards, grading journeys and instructor workflows were not executed. Moodle, PrairieLearn, FGPE and Open edX evidence is source/documentation evidence.

## Patterns worth applying

These are adaptations, not imported implementations or new domain features.

1. **A server-selected next action.** Pair the existing destination with course/mission context and the supplied reason. Avoid equally weighted dashboard widgets competing with Continue.
2. **Named prerequisite explanations.** A lock should identify the missing prerequisite where the existing read model supplies it. Do not derive eligibility from visual order or XP. Knowledge Check remains formative unless an actual backend rule says otherwise.
3. **Separate action consequences.** Run updates local preview, Save draft persists work and Submit requests academic evaluation. Keep this distinction in wording, placement and feedback.
4. **A single editing session.** Change pane visibility and workspace size without replacing the mounted editor, source, undo history or selection. Preserve existing sandbox restrictions.
5. **Evidence before interpretation.** Performance should show the assessment source, outcome and skill/course association. No evidence is not weak performance. Do not invent mastery percentages or confidence.
6. **Scope before teacher metrics.** Make classroom/course selection and report filters readable. Link a student or attention reason to its supplied evidence destination. A paginated roster is not a complete ranked attention queue.
7. **Readable histories.** Keep separate submissions, formative checks, Boss attempts and learning timeline events distinct. Do not synthesize success by merging records.

## Limits

Some GitHub HTML trees and raw pages failed through the search tool. Direct read-only GitHub API/raw-source retrieval supplied the selected source evidence. Kolibri's direct HTTP documentation fetch returned 403, but anonymous Chromium loaded the official guide and its classroom screenshot successfully.

No broad accessibility certification, instructor login, assessment security audit or load test of a reference project was performed. Public page screenshots establish composition only. Popularity was not used to rank quality. The strongest references are the ones whose inspected pattern answers a concrete CodeQuest workflow problem.
